2

Introducing Key Terms

In data systems, we use special terminology to describe how information is organised:

OBJECT

The "thing" you're storing information about

Example: Book, Student, Product, Song

ATTRIBUTES

The pieces of information you track about that object

Example: Title, Author, Genre, Price, Rating

Simple Way to Remember

OBJECT = The noun (what thing?) | ATTRIBUTES = The adjectives (what details?)

TEACHER DEMONSTRATION

Writing Queries in Everyday Language

1

What Is a Natural Language Query?

A natural language query is a way of describing how you want to search or filter data using everyday words, rather than code.

Think about it this way:

❌ What you DON'T say:

"I want book where genre equals mystery"

→
✓ What you DO say:

"I want to find all mystery books"

Natural language queries help us plan before we build the actual app features!

2

The Query Formula

Natural language queries follow a simple pattern. Let's break it down:

THE QUERY FORMULA

To find [WHAT YOU WANT], I would look in the [OBJECT] object and filter where [ATTRIBUTE] = [VALUE] and show the [ATTRIBUTE] attribute.

Don't worry if this seems confusing! We're going to work through examples together.

3

Worked Example: Library System

Scenario: A student comes to the library and says: "I want to find all mystery books."

Let's write this as a natural language query step by step:

Building the Query

STEP 1: Identify the object

What thing are we searching through? → Book

STEP 2: Identify the filter attribute

What piece of information helps us filter? → Genre

STEP 3: Identify the filter value

What specific value are we looking for? → "Mystery"

STEP 4: Identify what to show

What information do we want to display? → Title

THE COMPLETE QUERY:

"To find all mystery books, I would look in the Book object and filter where genre = 'Mystery' and show the title attribute."

4

Another Example: Books with Copies Available

Scenario: A student asks: "Which books can I borrow right now?"

This means we need to find books where there are available copies (more than 0).

Object:

Book

Filter Attribute:

availableCopies

Filter Condition:

greater than 0

Show:

title

Complete Query:

"To find books that can be borrowed, I would look in the Book object and filter where availableCopies is greater than 0 and show the title attribute."

Guided Example 1: Find Action Movies

User Request: "Show me all action movies"

Let's work through this together:

What object are we searching?

Answer: MOVIE

Which attribute helps us filter for action movies?

Answer: genre

What value are we looking for?

Answer: "Action"

What attribute should we show?

Answer: title

COMPLETE QUERY:

"To find all action movies, I would look in the Movie object and filter where genre = 'Action' and show the title attribute."

3

Guided Example 2: Highly Rated Movies

User Request: "Show me movies with a rating above 8.0"

Note: This time we're not looking for an exact match. We want ratings greater than a value!

Class Discussion Questions:

1. What object are we searching?

2. Which attribute tells us the movie's rating?

3. What's our filter condition? (Remember: we want ratings ABOVE 8.0)

COMPLETE QUERY:

"To find highly rated movies, I would look in the Movie object and filter where rating is greater than 8.0 and show the title attribute."

4

Different Types of Filters

We've now seen different ways to filter data. Here's a summary:

Equals (=)

Exact match

genre = "Action"

Greater Than (>)

Above a value

rating > 8.0

Less Than (<)

Below a value

duration < 90
